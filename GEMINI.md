# Welcome, Gemini! 🚀

This file is your starting point for contributing to **kafka-scribe**.

## 📍 Where am I?

You are in a high-performance Rust CLI tool for Kafka message capture, analysis, and replay.
We focus on **Security**, **Simplicity**, **Testability**, and **Performance**.

## 🗺️ Key Maps

Before you start, you **MUST** read these documents:

1.  **[AI Engineering Principles](docs/AI_ENGINEERING_PRINCIPLES.md)**: 🛡️ **MANDATORY**. Our coding standards.
2.  **[Implementation Guide](docs/IMPLEMENTATION_GUIDE.md)**: 🏗️ How we work and prioritize tasks.
3.  **[Task List](kafka_scribe_task_list.md)**: 📋 The current roadmap and status of tasks.
4.  **[Design Document](docs/design-document.md)**: 📐 The architectural blueprint.

## 🛠️ Quick Start

```bash
# Check the project status
cat kafka_scribe_task_list.md

# Run tests to ensure baseline
cargo test
```

## 🤝 Rules of Engagement

1.  **Check Dependencies**: Don't start a task if dependencies aren't ready.
2.  **Follow the Plan**: Stick to the `task.md` and `implementation_plan.md`.
3.  **Communicate**: Use `notify_user` if you are blocked or need clarification.
4.  **Update Docs**: If you change code, update the docs.

*Go build something amazing!* 🌟
