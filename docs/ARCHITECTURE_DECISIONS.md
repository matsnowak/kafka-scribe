# Architecture Decision Records (ADRs)

## ADR-001: MVP Storage Strategy
**Decision**: Start with file-based JSON storage only
**Rationale**: Faster time-to-market, simpler implementation
**Status**: Accepted

## ADR-002: External Tool Integration
**Decision**: Leverage grep, jq, SQL for analysis
**Rationale**: Avoid reinventing the wheel, leverage existing expertise
**Status**: Accepted
